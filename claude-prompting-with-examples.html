How to Use Examples in Claude AI Prompts

Words tell Claude what to do. An example shows Claude exactly how. This is the single most underused prompting technique — and the fastest way to close the gap between what you asked for and what you got.

Step-by-step workflow

Add examples to any Claude prompt — 5 steps
1

Find a real output you liked

The best examples are outputs Claude already produced that you were happy with. Copy them directly rather than writing a fresh example from scratch.

2

Start with one example, not several

One-shot is the sweet spot for most professional tasks. It's faster to write than multiple examples and usually outperforms a long written description.

3

Label the example clearly

Use Here is an example of the output I want: followed by the example, then Now do the same for: followed by your real input. Clear labels stop Claude from treating the example as the task.

4

Check the example's length and structure

Claude calibrates output length against your example. If your example is 80 words, expect roughly 80 words back — adjust the example if you want a different target.

5

Add a second or third example if variation is high

Move to few-shot only if the first example isn't capturing the full range of outputs you need — for example, summaries of both short and long articles.

When to skip examples: for open-ended creative tasks where you want Claude to surprise you, or analysis tasks where you want Claude's own structure and logic. An example can constrain the output in unhelpful ways when originality matters more than consistency.

Frequently asked questions

Frequently asked questions
Why does including an example in a Claude prompt improve the output?
An example shows Claude the exact format, tone, length and structure you want instead of leaving room for interpretation. Words describe the task; an example demonstrates the target, which closes the gap between what you asked for and what you get.
What is a one-shot prompt?
A one-shot prompt contains exactly one example of the desired output alongside your instructions. It is the sweet spot for most professional tasks — Claude matches the pattern from a single well-chosen example, which is faster to write than several examples and more precise than a long description.
When should I use few-shot prompting instead of one-shot?
Use few-shot — two to five examples — when one example is not capturing the full range of variation you need in the output. Few-shot prompting is best for complex or nuanced outputs where a single example would over-constrain the result.
What is the best source for an example to include in a prompt?
A real output Claude already produced that you were happy with. Copy it directly into your next prompt. Claude extracts the pattern rather than the content, so a genuine past output is almost always better than an example written from scratch.
When should I avoid using examples in a prompt?
Skip examples for open-ended creative tasks where you want Claude to surprise you, or for analysis tasks where you want Claude's own structure and logic. An example can constrain the output in unhelpful ways when originality matters more than consistency.
