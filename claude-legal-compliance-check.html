Claude AI for Compliance Checks and Gap Analysis

Comparing a policy against a regulation line by line is a grind. Paste both texts into Claude and get a structured gap analysis in minutes — what's covered, what's missing, and exactly which section needs fixing — ready for a compliance professional to validate.

Choose your situation — copy the prompt: 
Check the following document against the requirements listed below and identify any gaps.

Document to check: [Insert Document Text]
Requirements to check against: [Insert Regulation / Standard / Internal Policy Requirements]

For each requirement, state whether the document: (a) fully meets it, (b) partially meets it, or (c) does not address it. For gaps, note which section of the document is affected.

Crucial instruction: Base your analysis solely on the two texts provided. Do not add requirements from external regulations not included in the requirements text, and do not interpret ambiguous language as compliant.

Always use the current in-force version of the regulation. Paste into Claude.

Map each of the following requirements to the relevant section of the document provided, and note any requirements that are not addressed.

Requirements: [Insert Requirements List]
Document: [Insert Document Text]

Present the output as a table with columns: Requirement, Document Section, Status (Met / Partial / Gap).

Crucial instruction: Only reference sections that exist in the document provided. Do not suggest that a requirement is met if the document language is vague or ambiguous.

This table format pastes cleanly into a compliance tracker or Excel sheet.

I previously ran a gap analysis on this document and found the following gaps: [Paste Previous Gap List].

Here is the updated document: [Insert Updated Document Text].

For each previously identified gap, confirm whether it has now been resolved, partially resolved, or remains unresolved in the updated text. Do not re-analyse sections that were not flagged as gaps.

Crucial instruction: Base your assessment strictly on the updated text provided — do not assume a fix was made unless the wording explicitly addresses the gap.

Use this after rewriting non-compliant sections, to confirm the gaps actually closed.

Frequently asked questions

Frequently asked questions
What does Claude need to run a compliance gap analysis?
The document to check and the requirements it needs to meet — a policy, procedure or contract, and the regulation, standard or internal requirements to compare it against.
Does Claude know current regulations automatically?
No. Claude checks only against the requirements you paste into the prompt — it does not browse the web for the latest laws autonomously. Always use the active, in-force text of the regulation.
Why does the version of the regulation I use matter so much?
Because Claude checks against the requirements text you paste — an outdated version will produce an inaccurate gap analysis. Always confirm you are using the current in-force version before running the check.
Can a Claude compliance gap analysis be used as proof of compliance?
No. It can never be used as evidence of compliance or a sign-off that your organisation meets regulatory requirements. It is a starting point for expert review, not a substitute for it.
How should I prepare my source documents before running a gap analysis?
Strip out heavy formatting and clean up any broken characters or export artifacts before pasting the text in — messy source text makes it easier for Claude to misread the structure of the document.
