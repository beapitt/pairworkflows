Build a dynamic Excel report step by step

Turn a manual report into a dynamic model — 5 steps
1

Document your current manual process

Write down every step you currently do — be specific. "Copy column D from the export into column F", "Delete rows where Status = Closed", "Add subtotal by region". This list is your starting point for Claude.

2

Show Claude the source and output structure

Describe your source data — columns, location, update frequency — and the final report — what it shows and who uses it. Paste small samples of both if possible. The more specific, the better the formulas.

3

Let Claude analyse what can be automated

Claude tells you which manual steps can be replaced with formulas and which ones still need human judgment. Review the analysis before building anything — this shapes the whole approach.

4

Build and test one section at a time

Start with the most important parts — like using SUMIFS for subtotals or XLOOKUP for key lookups. Ask Claude for the formula, test it with real data, then move on. This prevents mistakes from compounding across the model.

5

Standardise the source data and document the model

Dynamic reports need clean, consistent source data — ask Claude for the ideal table structure. Once everything works, ask Claude to write a short maintenance guide and save it inside the workbook.

Test before going live: Run the completed model against at least two months of real historical data before using it live. This catches edge cases — extra regions, missing data, unusual values — that single-month testing misses.

Frequently asked questions

How do I automate a monthly report in Excel?
Replace static numbers with dynamic formulas like SUMIFS, XLOOKUP, and FILTER that pull data from a standardized raw data sheet. Claude can write these formulas once you describe your current manual process.
How do I make an Excel report update automatically?
Structure your source data as a clean table — no merged cells, consistent column names — then use dynamic formulas to reference that data. When you paste new data into the source sheet, your report formulas calculate the new results instantly.
What formulas replace manual copy-paste in Excel?
SUMIFS, COUNTIFS, XLOOKUP, FILTER, and UNIQUE are the primary tools — they aggregate and retrieve data dynamically based on the criteria you define, instead of you doing it by hand.
Can Claude automate every step of my monthly report?
No — and it will tell you so. Claude flags steps that still need human judgment, such as unusual exceptions, manual sign-offs, or decisions that depend on context a formula can't read. Those steps should stay manual.
What's the difference between SUMIFS and FILTER for dynamic reports?
SUMIFS aggregates numbers that meet criteria and works in every Excel version. FILTER returns the actual matching rows and is only available in Excel 365 — useful when you need the underlying records, not just a total. Tell Claude your Excel version and it will pick the right one.
