Step-by-step workflow

Use Claude Artifacts at work — 5 steps
1

Enable Artifacts in Settings

Go to Claude Settings and make sure Artifacts is enabled. It may be on by default — check under Features. Once enabled, Claude will automatically use Artifacts for appropriate outputs.

2

Ask for a deliverable, not a response

Use language that signals a finished output: Build me a one-page brief on X, Create a formatted report on Y, Produce an HTML email for Z. This triggers Artifact mode reliably.

3

Pick the right Artifact type for the job

Markdown for reports and briefs. HTML for emails and web pages. Code files for scripts and queries. Data visualisations for charts. Interactive tools for calculators. React components for UI work.

4

Iterate directly on the Artifact

Once an Artifact is open, ask Claude to change it without starting over: Add a section on risks, Make the tone more formal, Add a summary at the top. Claude updates the Artifact in place.

5

Copy or download when ready

Use the copy button on the Artifact to grab the full content in one click. For code Artifacts, copy the code directly into your IDE, script runner, or spreadsheet.

Mobile note: Artifacts work best in Claude.ai on desktop. Interactive tools and React components may not render fully on mobile. For document and code Artifacts, mobile works fine.

Frequently asked questions

Frequently asked questions
What is a Claude Artifact?
An Artifact is a standalone output — a document, code file, chart, or interactive tool — that Claude builds separately from the chat window. Instead of a longer chat reply, you get a finished deliverable you can copy, download, or share immediately.
How do I trigger Claude to create an Artifact?
Ask for a specific deliverable rather than a response — use language like "build me", "create a", or "produce a formatted" instead of "write" or "explain". The verb signals to Claude that you want a standalone output, and it triggers Artifact mode reliably.
What types of Artifacts can Claude create?
Six main types: Markdown documents for reports and briefs, HTML pages for formatted web content and emails, code files in any language, data visualisations and charts, interactive tools like calculators, and React components for web application interfaces.
Can I edit an Artifact after Claude creates it?
Yes. Once an Artifact is open, ask Claude to change it directly — add a section, adjust the tone, restructure it — without starting a new conversation. Claude updates the Artifact in place rather than producing a separate new version.
Do Artifacts work on mobile?
Document and code Artifacts work fine on mobile. Interactive tools and React components may not render fully on a phone screen. For the best experience with interactive Artifacts, use Claude.ai on desktop.
