How to Build a CapEx Budget Template in Excel

Build a CapEx planning template with Claude — 4 steps
1

Assign a category to each project

Common categories: Facilities, Equipment, Vehicles, IT/Software, Leasehold Improvements. Categories allow Claude to build SUMIFS-based subtotals per category — useful for board reporting and budget allocation by department.

2

Specify spend timing, not just total cost

Capital projects rarely pay out in a single lump sum. Break each project into the months or quarters when cash will actually leave the business — e.g. "50% Q2, 50% Q3". This feeds the spend-phasing section and connects directly to your cash flow forecast.

3

Include salvage values and useful lives

Even rough estimates matter. Claude calculates indicative annual depreciation for each project so leadership can see the ongoing P&L impact alongside the cash outlay. Use 0 for salvage value if the asset will be fully written off.

4

Set the approval status for each project

Use four stages: Proposed, Submitted, Approved, Rejected. Claude creates a data-validation dropdown and filters totals by status — so the template shows both committed spend (Approved) and the full pipeline (Submitted + Proposed) in one view.

Frequently asked questions

What is the difference between CapEx and OpEx in Excel planning?
CapEx (capital expenditure) is spending on long-term assets — equipment, vehicles, property — that gets capitalised on the balance sheet and depreciated over time. OpEx (operating expenditure) hits the income statement immediately. This template handles CapEx only: each project is tracked as an asset with a useful life and a depreciation schedule.
Can Claude phase CapEx spending across multiple months?
Yes. The Phase spend prompt distributes each project's total cost across the months you specify — for example, 30% in Q1 and 70% in Q2. Claude does not smooth or average; it follows your timing exactly and gives you a monthly cash outflow row ready to paste into Excel.
How does this template connect to depreciation?
The template includes an annual depreciation column per project using straight-line: (Cost − Salvage) / Useful Life. For a full monthly depreciation schedule with multiple methods, pair this with the fixed asset depreciation workflow.
Should I include projects that haven't been approved yet?
Yes. The Approval Status column tracks Proposed, Submitted, Approved, and Rejected projects in one view. SUMIFS totals filter by status automatically, so leadership sees both committed spend and the full pipeline — not just what's already signed off.
