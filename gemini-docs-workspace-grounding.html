How to Use Gemini with Google Drive Files in Google Docs

Instead of copying and pasting data into your prompts, reference your Drive files directly with @ in the Gemini side panel. Gemini reads your actual Sheets, Docs, and PDFs and generates text grounded in your real company data — not AI guesses.

In the Gemini side panel, type this prompt — replace the
@ references with your actual file names:

Act as a senior analyst. Write a quarterly performance report
for the [Department] team covering [Quarter, Year].

Use these files as your only sources:
- @[Your Q results spreadsheet] — extract the exact figures
  for revenue, costs, and headcount
- @[Your OKR tracking doc] — extract the status of each
  objective: On Track / At Risk / Complete
- @[Your previous quarter report] — use as context for
  quarter-on-quarter comparison

Structure the report:
1. Executive Summary (under 150 words — key number and trend)
2. Results vs Targets (table: Metric | Target | Actual | Δ)
3. OKR Status (one line per objective)
4. Key risks heading into next quarter (max 3)

Rules:
- Use only figures from the referenced files.
- If a figure is missing from the files, write [Data missing]
  rather than estimating.
- Do NOT use percentages not in the source files.

Step-by-step workflow

Use Gemini with Drive files — 5 steps
1

Check your files are in Google format

Gemini can read Google Docs, Google Sheets, Google Slides, and PDFs stored in Drive. It cannot read .xlsx or .docx files directly. Convert them first: open the file in Drive → File → Save as Google Docs/Sheets. This takes 10 seconds and makes the file instantly referenceable.

2

Open the Gemini side panel — not Help me write

In Google Docs, click the Gemini icon in the top-right corner to open the side panel. This is the context-aware assistant that can hold a multi-turn conversation and reference up to several Drive files. The inline "Help me write" button is for quick single inserts — use the side panel for anything referencing external files.

3

Reference files with @ in your prompt

In the side panel, type @ and start typing the file name. A dropdown shows matching files from your Drive — select the one you want. You can reference multiple files in one prompt. Gemini reads the files and uses their content when generating the response. You can only reference files you already have access to.

4

Verify every cited figure before using it

When Gemini generates text from a Drive file, it shows citation markers — small interactive links next to figures. Click each one to verify it matches the source document. If a figure appears without a citation link, Gemini may have estimated it. Flag these as [Verify] and check manually before the document goes anywhere.

5

Keep source files clean and consistently named

Grounding works best when your source files are tidy — one clear tab per topic, consistent column headers, no merged cells. Give files descriptive names like "Q2 2025 Results — Operations" rather than "Copy of Sheet1". This makes them easier to find via @ and easier for Gemini to navigate once referenced.

Tip: For recurring reports (monthly, quarterly), keep a single master template Doc and a live source Sheets file with the latest data. Each reporting cycle, open the template, reference the updated Sheet with @, and ask Gemini to update the numbers section only — keeping your structure intact.

Frequently asked questions

What is Workspace grounding in Gemini?
Workspace grounding means Gemini reads your actual Google Drive files — Docs, Sheets, Slides, PDFs — when generating text, instead of relying on its training data. You reference files using @ in the Gemini side panel. Gemini can only access files you already have permission to open.
How do I reference a Google Drive file in a Gemini prompt?
In the Gemini side panel in Google Docs, type @ and start typing the file name. A dropdown shows matching files from your Drive. Select the file and continue your prompt. Gemini reads the file and uses its content when generating your response.
Can Gemini access files I don't have permission to view?
No. Gemini strictly respects your existing Google Workspace permissions. It can only read files you can already open yourself. Shared drives, restricted folders, and files owned by others follow the same access rules as if you opened them manually.
What file types can Gemini read from Google Drive?
Gemini reads Google Docs, Google Sheets, Google Slides, and PDFs. It cannot read .xlsx or .docx files directly — convert them to Google format first using File → Save as Google Docs/Sheets.
What is the difference between the Gemini side panel and Help me write?
"Help me write" generates text at your cursor position inside the document — good for quick paragraph inserts. The side panel is a persistent assistant that holds a conversation, reads your whole document, and can reference Drive files with @. For anything involving external file references, use the side panel.
