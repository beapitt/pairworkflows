Step-by-step workflow

Remove duplicates in Excel safely — 5 steps
1

Make a copy of your data first

Copy the entire sheet to a new tab before touching anything. Remove Duplicates can be undone with Ctrl+Z during the current session, but once you save and close the file the deletion is permanent. Working on a copy means you can always go back. If your dataset is large, paste values only to keep the backup fast.

2

Use the identify prompt to choose the right columns

Paste your headers and a sample into Claude and ask which columns together define a unique record. The answer is rarely a single column — it's usually a combination like Customer + Product + Date. Using too few columns deletes valid rows; using too many misses real duplicates.

3

Add a COUNTIFS helper column and review flagged rows

Before deleting anything, add the COUNTIFS formula Claude gives you in a helper column. Filter on values greater than 1, then check every column in those rows — look for notes, flags, or amounts that differ from the row you plan to keep. If the duplicate has unique data, merge it into the kept row first.

4

Sort your data if you need to control which row is kept

Excel's Data → Remove Duplicates always keeps the first occurrence and deletes the rest. If you need the most recent record, sort by date descending first. If you need the highest value, sort by amount descending. The sort determines which row ends up first — and therefore which row survives.

5

Run Data → Remove Duplicates and verify the row count

Go to Data → Remove Duplicates, check only the columns Claude identified, and click OK. Excel will tell you how many rows were removed and how many remain. Verify this number against your COUNTIFS formula — the count of rows with value greater than 1 should equal the rows removed.

Important: Remove Duplicates deletes rows immediately. You can undo with Ctrl+Z during the current session, but once you save and close the file the deletion is permanent. Always work on a copy, and always run the COUNTIFS check first.

Frequently asked questions

How do I remove duplicates in Excel?
Go to Data → Remove Duplicates. In the dialog, select the columns that together define a unique record — for example, Customer + Product + Date, not Customer alone. Excel keeps the first occurrence of each unique combination and deletes the rest. Always work on a copy of your data first — the deletion becomes permanent once you save and close the file.
How do I remove duplicates from a specific column in Excel?
In the Remove Duplicates dialog, uncheck all columns except the one you want to deduplicate. For example, to remove rows where the Email column repeats, uncheck everything and leave only Email checked. Excel keeps the first row with each unique email value and removes the rest.
How do I keep the most recent duplicate instead of the first one?
Excel's Remove Duplicates always keeps the first row it encounters. To keep the most recent record, sort your data by date descending before running Remove Duplicates — the newest record will appear first and will be the one kept. Use the "Choose which to keep" prompt above to get the exact sort instructions for your dataset.
Can Claude remove duplicates from my Excel file directly?
Claude can analyse an XLSX file you upload and, with the right tools enabled, create or edit spreadsheets. When you paste in headers and sample rows, Claude tells you which columns to use, how to sort, and gives you the COUNTIFS formula to flag duplicates for review. The final deletion is done by you using Excel's built-in Remove Duplicates feature.
What is the COUNTIFS formula to find duplicates in Excel?
Use =COUNTIFS($A$2:$A2,A2,$B$2:$B2,B2) in a helper column, adjusting the column references to match your duplicate-defining columns. The expanding range $A$2:$A2 counts how many times the combination has appeared up to and including the current row. A value of 1 means first occurrence; 2 or more means duplicate. Filter on greater than 1 to review before deleting.
