How to Build a Month End Close Checklist in Excel with Claude AI

Cut close time, not quality. Build a structured month-end close checklist in Excel with task tracking, owner assignments, and status formulas using Claude AI.

Copy this prompt to generate your checklist template: 
ROLE
You are a financial controller designing a robust month-end close tracker in Excel.

OBJECTIVE
Create a checklist that tracks our close process end-to-end.

CLOSE TASKS:
[Paste your task list here — one per line]

CONSTRAINTS
- Create an Excel table with these columns: #, Task, Owner, Deadline (Working Days after month-end), Status, Notes.
- Status column must use Data Validation (dropdowns): "Not Started", "In Progress", "Pending", "Complete".
- Add a cell at the top where I can enter the actual Month-End Date. All deadlines must be formulas (WORKDAY) referencing this date.
- Add a summary area (COUNTIF) that calculates: Total tasks, Tasks complete, and % completion.
- Add a table tracking completion count by Owner.
- Do NOT use VBA/Macros. Use only formulas and data validation.

OUTPUT
- A tab-separated table I can paste into Excel.
- A step-by-step guide on how to set up the Data Validation and Conditional Formatting.

Workflow

1

Sequence your tasks

Order tasks by dependency. List items that must occur first (e.g., Bank Rec) at the top.

2

Assign ownership

Use named roles. Assigning "J. Patel" is better than "Accounting team" — accountability creates speed.

3

Verify status formulas

Ensure your COUNTIF formula is locked to the status range so it updates instantly when a task is marked 'Complete'.

FAQ

Can Claude generate the checklist from my existing process?
Yes. Paste your current steps into the prompt, and Claude will restructure them into the table format.
How do I track completion percentage automatically?
The prompt includes a requirement for a COUNTIF formula that divides completed tasks by total tasks.
