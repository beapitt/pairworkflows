Step-by-step workflow

Build a month-end close checklist with Claude — 4 steps
1

Sequence tasks by dependency

Order your close tasks by dependency before pasting into the prompt. Bank reconciliation must come before accruals. Fixed asset depreciation must come before the trial balance. Claude builds the checklist in the order you give — it won't reorder tasks without being asked.

2

Assign named owners, not team names

Write "J. Patel" not "Accounting team". Named ownership creates accountability and enables the per-owner COUNTIFS summary. Claude generates that summary table automatically when owners are specific.

3

Set up Data Validation for the Status column

In Excel: select the Status column → Data → Data Validation → List → type exactly: Not Started,In Progress,Pending,Complete. These must match the COUNTIF formula text exactly — one space difference returns 0.

4

Enter the Month-End Date once and let WORKDAY do the rest

Claude creates a single input cell for the Month-End Date. All deadline cells reference it with =WORKDAY(MonthEndDate, n). Change one date at the start of each month and every deadline updates automatically.

Tip: Add Conditional Formatting to the Status column — green fill for Complete, yellow for In Progress, red for Not Started — so the tracker reads at a glance without opening filters.

Frequently asked questions

What tasks should a month-end close checklist include?
A typical checklist covers bank reconciliation, accounts receivable and payable reviews, accrual entries, intercompany eliminations, fixed asset depreciation, revenue recognition, trial balance review, and financial statement preparation. The exact list depends on your organisation's complexity — paste your own tasks into the prompt and Claude structures them without inventing extras.
Can Claude generate the checklist from my existing process?
Yes. Paste your current close steps into the prompt and Claude restructures them into a trackable Excel table with owner, deadline, status, and notes columns. The guardrail line "Do NOT invent tasks I haven't listed" ensures Claude doesn't add steps that don't apply to your organisation.
How do I track completion percentage automatically in Excel?
Claude builds a COUNTIF-based formula that counts rows marked "Complete" and divides by total tasks. This updates in real time as your team changes each task's status. The formula only works if status values match exactly — use Data Validation dropdowns to enforce consistency.
Does this replace close management software?
No. This is for teams that manage the close in spreadsheets and need a faster way to build and maintain the checklist. If you use dedicated close software, this template can serve as a lightweight backup or secondary tracker.
