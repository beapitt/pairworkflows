FAQ

Can AI write Excel formulas?
Yes. ChatGPT, Claude and Gemini can generate Excel formulas when you provide the column structure, the result you need and your Excel version. Always test the formula with real data before using it in a live workbook.
Does this work with ChatGPT, Claude and Gemini?
Yes. The builder supports ChatGPT, Claude and Gemini. Select the AI you want to use and the generated prompt will be adapted for that provider.
Can I use these prompts with Google Sheets?
Yes. Many spreadsheet tasks work in both Excel and Google Sheets. Select the spreadsheet app where available and specify any functions or features that are unique to your environment.
Can AI debug broken Excel formulas?
Yes. Include the broken formula, the error or unexpected result, and a few representative rows. The AI can help identify likely causes and suggest a corrected formula, which you should verify in Excel.
Can AI write VBA macros?
ChatGPT, Claude and Gemini can generate VBA code from a clear description of the task. Review and test generated macros in a copy of your workbook before using them on important data.
Does this work with Excel 2016 and 2019?
Yes, but you should specify your Excel version in the prompt. Newer functions such as XLOOKUP, FILTER and dynamic arrays are not available in every older Excel version.
Do I need a paid AI account to use these prompts?
No. You can use many of these prompts with free versions of ChatGPT, Claude or Gemini. File uploads, longer context and other advanced features may depend on the provider and plan you use.
