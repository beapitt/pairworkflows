2

3

Run the build prompt

Paste your register into Claude using the 'Build from register' prompt. Claude will generate the structured table using built-in Excel functions like =SLN() or =DDB() instead of manual maths.

4

Verify the fully depreciated asset guardrail

Look at an asset that has reached the end of its useful life. The annual depreciation for that year should be zero, and the Net Book Value (NBV) must equal the salvage value. If NBV is negative, the guardrail formula failed.

Frequently asked questions

Frequently asked questions
Which Excel function does Claude use for straight-line depreciation?
Claude uses Excel's built-in SLN function, which takes three arguments: cost, salvage value, and useful life. The formula is =SLN(cost, salvage, life). Claude can also build the calculation manually as (Cost − Salvage) / Life if you prefer.
Can Claude handle mid-year asset additions?
Yes. Include the in-service date for each asset and tell Claude your convention — half-year, mid-month, or exact-day. Claude will prorate the first-year and last-year depreciation accordingly.
What is the difference between SLN, DDB, and SYD in Excel?
SLN spreads the depreciable amount equally over the useful life. DDB (double declining balance) front-loads depreciation by applying a fixed rate to the declining book value. SYD (sum of years' digits) also front-loads but less aggressively than DDB. Claude can build schedules using any of these methods.
How do I handle fully depreciated assets in the template?
The prompt instructs Claude to add a check that stops depreciation once net book value reaches the salvage value. Fully depreciated assets remain in the register with zero annual depreciation and an NBV equal to salvage.
