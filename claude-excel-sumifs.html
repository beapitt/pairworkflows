Frequently asked questions
Why does my SUMIFS return 0?
Usually a range size mismatch — your sum range and criteria ranges must be exactly the same number of rows. Other common causes: missing quotes around text criteria, dates stored as text, or extra spaces in the data. Paste the formula and 3 sample rows into Claude and it will find it.
Can SUMIFS handle OR conditions?
Not in a single formula. Write two separate SUMIFS and add them with +: =SUMIFS(E:E,A:A,"North")+SUMIFS(E:E,A:A,"South"). Ask Claude for the OR prompt above and it will write this for you.
How do I use date ranges in SUMIFS?
Wrap the operator in quotes and join it to the date with &: use ">="&DATE(2026,1,1) or ">="&A1. Make sure the date column contains real Excel dates — not text that looks like a date.
SUMIFS vs SUMIF — which should I use?
Use SUMIFS even when you only have one condition. The argument order is more consistent and it's easier to add more criteria later without rewriting the formula.
