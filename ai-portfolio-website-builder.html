Save the code as index.html — open a text editor (Notepad, TextEdit, VS Code), paste the code, and save the file.
3
Add your images — rename your profile photo your-photo.jpg and your portfolio images portfolio-1.jpg, portfolio-2.jpg, etc. Put them in the same folder as index.html.
4
Replace the placeholder text — open index.html in a text editor and search for [PLACEHOLDER] to find all the text to update.
5
Open in your browser — double-click index.html to preview your site. To publish it online, upload the folder to any web host.
